# LingoLIVE - Admin Portal App

Portal de gerenciamento global para administradores do LingoLIVE.

## Responsabilidades
- Painel de controle de usuários, assinaturas, controle de chaves de API externas (OpenAI, Gemini).
- Monitoramento de custos de tokens e performance do sistema.
- Gerenciamento de campanhas promocionais e conteúdos globais.
