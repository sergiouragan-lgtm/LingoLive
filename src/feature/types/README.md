# TypeScript Types (`feature/types`)

Esquemas de dados estritos, interfaces comuns, uniões (unions), tipos utilitários e constantes imutáveis do TypeScript compartilhados estritamente dentro desta funcionalidade.

## Exemplos
- `interface SessionConfig`: Parâmetros de idioma, nível de proficiência e avatar escolhido.
- `type VoiceId`: Lista de IDs de voz suportados pela ElevenLabs no LingoLIVE.
- Mapeamentos estáticos de apoio de tipos.
