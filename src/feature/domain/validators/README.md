# Domain Validators (`feature/domain/validators`)

Regras e rotinas de validação de dados de negócios.

## O que colocar aqui
- Validadores estruturais para novos cadastros (e-mails corporativos, formato de senhas).
- Regras de conformidade pedagógica para turmas escolares B2B.
- Validação de formato de resposta para os prompts de orquestração de IA.
