# Domain Models (`feature/domain/models`)

Entidades e modelos de domínio ricos que representam conceitos reais de negócios.

## Exemplos
- `Estudante.ts`: Entidade que dita as lógicas de progresso, cálculo de ofensiva (streak) e limites de assinatura do aluno.
- `SessaoPratica.ts`: Representação de uma sessão de conversa do tutor de IA, contendo as lógicas de cálculo de tempo ativo e grau de engajamento do utilizador.
