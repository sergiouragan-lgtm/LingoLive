# Presentation Components (`feature/presentation/components`)

Os componentes de UI estruturados que formam os painéis de interação.

## Lembretes Importantes
- Os componentes devem herdar os tokens de design globais (`@lingolive/design-system` ou `@lingolive/ui`).
- Utilizar apenas Tailwind CSS para toda a estilização.
- Garantir a acessibilidade do utilizador (leitor de tela, contraste de cores e conformidade iFrame).
