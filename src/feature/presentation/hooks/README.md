# Presentation Hooks / Controllers (`feature/presentation/hooks`)

Custom hooks do React criados especificamente para guiar as lógicas visuais e interações desta funcionalidade.

## O que colocar aqui
- `useAudioRecorder.ts`: Lógicas para capturar áudio, pausar e transmitir buffers para a API de transcrição do Whisper.
- `useSpeechRecognition.ts`: Controlador de conversão local ou de nuvem para auxiliar na fluência interativa.
- `usePracticeSession.ts`: Gerenciador de estado local e síncrono para conduzir e ditar os passos de conversação da sala de prática ativa.
