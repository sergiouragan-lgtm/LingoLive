# Presentation Layer (`feature/presentation`)

Camada responsável por interagir diretamente com o utilizador e disponibilizar os elementos visuais na tela. Toda a manipulação do DOM e a experiência visual do estudante residem aqui.

## Subdiretórios
- **components/**: Elementos visuais React puros e reutilizáveis organizados com Tailwind CSS.
- **hooks/**: Controllers React baseados em Hooks para gerenciar estados locais, estados globais e ligar a UI aos Casos de Uso.
