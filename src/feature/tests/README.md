# Automated Testing Layer (`feature/tests`)

Contém a suite de testes unitários de alta fidelidade e cenários de simulação para garantir o funcionamento correto e livre de bugs desta funcionalidade.

## O que colocar aqui
- Testes unitários para casos de uso de aplicação (com Vitest ou Jest).
- Testes de renderização de componentes de apresentação.
- Mocks para simulação de chamadas do Gemini API e logs da ElevenLabs.
- Arquivos de sementes (seed) de teste com diálogos pré-gravados em vários idiomas.
