# Infrastructure Services (`feature/infrastructure/services`)

Serviços e gateways de integração tecnológica que consomem serviços de infraestrutura externa.

## O que colocar aqui
- Chamadas para sintetização de áudio TTS na API da ElevenLabs.
- Proxies e conectores de chamadas HTTP para o provedor Gemini 3.5 Flash.
- Conexão e sincronização offline com bancos locais (IndexedDB ou SQLite embarcado).
