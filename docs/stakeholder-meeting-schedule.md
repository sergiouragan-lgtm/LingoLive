## During Meeting (30-40 min)

### Opening (2 min)
- Thank everyone for attending
- Set agenda: 20 min presentation, 10 min Q&A
- State decision needed: Phase 1 approval (yes/no/conditional)

### Presentation (20-25 min)
- Follow slide deck with speaker notes
- Watch for engagement/confusion
- Pace: slower is better than rushed
- Key phrase to repeat: "Phase 1 is a controlled test. We can rollback anytime."

### Q&A (10-15 min)
- Listen fully before answering
- Validate concerns ("That's a fair question...")
- Answer with data (use spike metrics)
- Offer follow-ups: "Let me get you more detail on X by Thursday"

### Closing (3 min)
- Summarize decision being made
- Confirm next steps if approved
- Set timeline for communication
- Thank attendees for time

## Contingency Plans

### If decision maker can't attend:
- Offer 1-on-1 briefing before/after meeting
- Get proxy decision maker
- Document decision in writing if needed

### If technical issue occurs (projector fails, etc.):
- Have presentation PDF ready
- Have speaker notes printed
- Can present from laptop screen sharing
- Have backup laptop ready

### If tough questions derail timeline:
- "Great question. Let me follow up on that by [DATE] with more detail."
- Offer post-meeting deep dive: "1-on-1 meeting with [expert] on this topic?"
- Don't let one topic consume all Q&A time

### If approval is withheld:
- Remain professional: "We'll gather that feedback and come back stronger."
- Ask: "What would help us move forward?"
- Set clear timeline for follow-up
