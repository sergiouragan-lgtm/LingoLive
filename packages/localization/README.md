# LingoLIVE - Localization (`@lingolive/localization`)

Gerenciamento de suporte internacional, traduções, termos regionais, gírias locais e variantes linguísticas do Português (Angola, Portugal, Brasil, etc.) e outros idiomas.

## Conteúdo Futuro
- Dicionários estáticos de termos locais (ex: `localizationData.ts`).
- Hooks de tradução ativa baseados nas preferências do usuário.
