# LingoLIVE - UI Package (`@lingolive/ui`)

Biblioteca de componentes atômicos compartilhados altamente polidos, baseados em Tailwind CSS e com suporte completo a acessibilidade.

## Conteúdo Futuro
- Botões, Cards, Modais, Inputs estruturados, Menus de navegação e seletores.
- Componentes interativos de gravação e reprodução de áudio.
- Animações fluidas de feedback baseadas em `motion/react`.
