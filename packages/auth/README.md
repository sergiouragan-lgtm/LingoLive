# LingoLIVE - Auth Package (`@lingolive/auth`)

Pacote responsável pelas lógicas de segurança, autenticação e tokens integrados nativamente com o Firebase Authentication (Auth).

## Conteúdo Futuro
- Contextos do React para controle de estado de usuário logado (`AuthContext`).
- Middlewares de autenticação para as rotas Express/Node.js.
- Regras de controle de acessos baseados em papéis (Roles: Admin, Professor, Aluno, RH).
