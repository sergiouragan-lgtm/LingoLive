# Firestore Emulator Prerequisites

To run the Firestore Emulator locally, Java 17 or higher is required.

## Installation

This project environment runs on Debian/Ubuntu-based systems. To install the required Java runtime, run the following command in your terminal:

```bash
sudo apt-get update && sudo apt-get install -y openjdk-17-jre-headless
```

## Verification

After installation, verify the installation by running:

```bash
java -version
```

It should output the Java version information.
